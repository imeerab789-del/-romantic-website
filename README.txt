Happy Anniversary - GitHub Pages site

1. Upload everything in this folder to a public GitHub repository (index.html must be in the root).
2. Settings > Pages > Branch: main, folder: / (root) > Save.
3. Open https://USERNAME.github.io/REPO-NAME/

Everything (photos, song, styles, scripts) is inside index.html. Pages: #home #about #gallery #moments #contact. Start PIN is set in the C2 object in index.html.
